Learn how to plan 20 small games, reuse a core project structure, build 2D and 3D prototypes, and ship each game — with Godot scenes, GDScript examples, and a reusable template. Built for aspiring game developers, Godot learners, and challenge participants. **Completely free.** No signup. No paywall. No hidden chapters.
